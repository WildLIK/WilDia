# WilDia

Android-приложение для офлайн-диагностики автомобилей по OBD2 (ELM327) через Bluetooth BLE и Classic SPP.

- Чтение и расшифровка кодов ошибок (DTC), живые датчики, графики и профили автомобилей.
- Встроенная офлайн-база кодов и параметров, безопасное чтение VIN/ЭБУ и экспорт отчётов.
- Текущая версия: **v0.5.5** (`versionCode 15`).
- Скачать сборки и обновления: https://github.com/WildLIK/WilDia/releases
